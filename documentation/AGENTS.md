# Documentation instructions

- Keep documentation aligned with actual source behavior and the npm scripts in `package.json`.
- Make rules specific and actionable; avoid duplicating conflicting requirements across files.
- When changing test conventions, update the corresponding `jest.md` or `storybook.md` rules and link to them from the root `AGENTS.md`.
- Do not include real credentials, mailbox contents, or other private user data in documentation examples.
