# Renderer instructions

- Before changing renderer UI or behavior, read the root `AGENTS.md` and the relevant rules in `documentation/jest.md` and `documentation/storybook.md`.
- Keep renderer code in TypeScript/TSX and follow the existing component-folder organization.
- Prefer reusable, accessible React components and preserve existing application behavior.
- Include coverage for user-visible changes and run the appropriate Jest and Storybook tests.
